Критерії прийому роботи наставником
Проект
«А1» Використовується методологія БЕМ.

«A2» Використовується препроцесів SASS.

«A3» У файлах index.html і portfolio.html підключений мінімізований файл стилю main.min.css з папки css.

«A4» При перегляді сторінки на будь-якому пристрої шириною від 320 пікселів не з’являється горизонтальна смуга прокрутки.

«A5» Скрипт мобільного меню, підключений до HTML окремим файлом mobile-menu.js.

Разметка
«B1» На всіх сторінках у блоці <head> є метатег viewport.

«B2» Всі фонові та контентні растрові зображення - відгукні, і підтримують екрани з щільністю x1 і x2.

«B3» Для перегляду фонових зображень використано медіа-фукцнії min-device-pixel-ratio і min-resolution.

«B4» Виповнена розмітка мобільного меню.

Оформлення
«C1» При написанні стилю використано Mobile First підхід і медіа-функція (min-width: ).

«C2» Стилі необхідні тільки в визначеному проміжку, закриті в медіа-запитах (min-width: ) і (max-width: ) або тільки (max-width: ).

«C3» В медіа-запитах відсутнє більш глибоке дублювання стилів.

«C4» Верстка виконана відносно трьох точок перелому: 480px, 768px і 1200px.

«C5» Виконано оформлення мобільного меню.
